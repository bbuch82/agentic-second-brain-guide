# Archive notice — guide v1

This directory holds the first edition of the guide exactly as it was published,
unedited. It is kept for two reasons: external links point into it, and forks were
made from it.

It is no longer maintained. Its architecture is superseded by v2 in the repository
root, which treats the vault as the contract between several runtimes rather than
describing a single installation.

- Read v1 from the top: [README.md](./README.md)
