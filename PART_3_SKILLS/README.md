# Part 3 — Skills

A capability described only in a prompt cannot be versioned, tested, or reviewed. This
part turns capabilities into artifacts: a contract, sometimes an implementation, and a
dated record of why it is the way it is. Four patterns cover most of the work, and the
last chapter shows why stages compose better than an orchestrator.

> A capability you cannot version, test, or read is not a capability. It is a prompt you got lucky with.
