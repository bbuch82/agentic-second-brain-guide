# Part 2 — Build

Four stages, each ending in a system that is useful on its own. Stage 0 needs no
infrastructure at all and takes half an hour; stage 3 is a full installation with
scheduled jobs, a chat interface, and rules written from observed failures. Stop at any
stage and you still have something.

| # | Chapter | Delivers |
|---|---|---|
| 05 | [Stage 0 — Thirty Minutes](./05_stage-0-thirty-minutes.md) | A working vault, two rule files, one skill. No server |
| 06 | [Stage 1 — Make It Autonomous](./06_stage-1-autonomous.md) | A hardened host, a runtime, a chat interface, two scheduled jobs |
| 07 | [Stage 2 — Close the Loop](./07_stage-2-close-the-loop.md) | Git and continuous sync, Obsidian, and the concurrency rules |
| 08 | [Stage 3 — The System Files](./08_stage-3-system-files.md) | All nine governance files, in the order the need appears |

> Each stage ends with a system that is useful on its own. A build that is only valuable when finished is a build that gets abandoned.
