# Part 1 — Principles

Four ideas that decide everything downstream: why the data format rather than the
agent is the contract, why the work splits into a layer that runs without you and one
that runs with you, why the rules live in files the agent reads, and where a hosted
product beats this outright. Read this part even if you never build the system — the
mental model is the transferable part.
